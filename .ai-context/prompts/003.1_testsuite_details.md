# PDD Feature Spec: Test Suite Details

## 1. Feature Description
Provide dedicated interfaces for creating new test suites when the user clicks on "Add Suite" button at top right corner.

---

## 2. Technical Contracts & Mappings

### Backend REST Contracts
* **Fetch Suites:** `GET /api/testsuite/testsuites` (Port `7780`)   
  * Returns an array of test suites.
* **Create Suite:** `POST /api/testsuite/testsuite` (Port `7780`)
  * Request payload: `{ "name": "...", "description": "...", "releaseid": 10 }`.

---

## 3. Frontend UI Specifications

### Test Suites View (`src/pages/AddTestSuite.jsx`)
* **Visuals:** Show a screen with fields required for creating a test suite: name, description. 
* **Release Id:** Release id that is required for association should be passed from the release id selected on the dashboard. 
* **Buttons:** This Add Suites screen should have two buttons at the bottom. 
1. Cancel: This should take the user back to the Test Suites List View.
2. Add Suite: This should take the user back to the Test Suites List View after creating the test suite.
* **Interactivity:** Creating a test suite triggers a `POST` request to Test Suite Management Services and immediately updates the active test suite list on success with zero UI lag.
