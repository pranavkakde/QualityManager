# PDD Feature Spec: Test Suite Status Reference

## 1. Feature Description
Add a relational database reference table called `TestSuiteStatus` to categorize the progress of Test Suites in the QualityManager platform. Mapped statuses are restricted to standard integer IDs for Sequelize ORM lookup.

---

## 2. Database Specification

### SQL Server DDL (`db/schema.sql` addition)
```sql
CREATE TABLE [dbo].[TestSuiteStatus] (
    [statusid] INT PRIMARY KEY,
    [statusname] NVARCHAR(50) NOT NULL
);
```

### Reference Values (`db/mock_data.sql` seed)
| statusid | statusname | Description |
| :--- | :--- | :--- |
| `1` | `Created` | The suite has been newly defined with zero runs |
| `2` | `In Progress` | Cases inside the suite are actively executing |
| `3` | `Completed` | All cases inside the suite have finished run status |

### Foreign Key Constraint
Link `dbo.[testsuites]` table `statusid` to the reference table:
```sql
ALTER TABLE [dbo].[testsuites]
ADD FOREIGN KEY ([statusid]) REFERENCES [dbo].[TestSuiteStatus]([statusid]);
```
